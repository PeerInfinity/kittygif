Author a level in the official editor, play it in RWIA

The web version of Robot Wants Kitty has a full level editor. Levels it makes can be converted here into the GIF dialect the compilation reads, which means a level authored in the official editor can be played in the compilation.

Measured, not imagined. Every step below was carried out once, in a browser, on 2026-08-31, and only the steps that worked are written down. The level that came out is tests/data/webeditor-v16.kitty in the repository, and the two console snippets are the ones that ran, verbatim.

1 · Author the level

  1. Open robotwantskitty.com/web and pick a control scheme when it asks.
  2. From the title screen go to MAKER MALL → MY LEVELS → CREATE NEW LEVEL, type a name, OK.
    Signing in is only needed to publish a level. Creating and saving one works while the bar still says “touch here to sign in”.
  3. In the editor, open the layout palette (the blocks icon on the right rail), choose a tile, and click cells to place it. The brush icon paints surfaces; the robot and the kitty are already on the grid and can be dragged.
  4. Leave the editor with “BACK TO LEVELS”.
    This is the step that writes the file. Reloading the page from inside the editor loses the level — the storage key does not exist until you leave.

2 · Get the .kitty out of the browser

The web build keeps its files in the page's own IndexedDB, so the export is a snippet in the developer console (F12 → Console; some browsers make you type allow pasting once). First, list what is there:

indexedDB.open("/RAPTISOFT_SANDBOX", 21).onsuccess = (e) => {
  e.target.result.transaction(["FILE_DATA"], "readonly")
    .objectStore("FILE_DATA").getAllKeys().onsuccess = (ev) =>
      console.log(ev.target.result.filter(k => k.includes("EXTRALEVELS64")));
};

Your levels appear as /RAPTISOFT_SANDBOX/RWK/EXTRALEVELS64/<name>.kitty.

Then download one — put your level's name in the first line:

indexedDB.open("/RAPTISOFT_SANDBOX", 21).onsuccess = (e) => {
  const name = "KITTYGIF DEMO";
  const key = "/RAPTISOFT_SANDBOX/RWK/EXTRALEVELS64/" + name + ".kitty";
  const store = e.target.result
    .transaction(["FILE_DATA"], "readonly").objectStore("FILE_DATA");
  store.get(key).onsuccess = (ev) => {
    if (!ev.target.result) { console.log("no such level:", key); return; }
    const a = document.createElement("a");
    a.href = URL.createObjectURL(new Blob([new Uint8Array(ev.target.result.contents)]));
    a.download = name + ".kitty";
    a.click();
  };
};

The IndexedDB route was documented first by MrMasterplan's rwklevelfiles (a Tiled extension for these files, GPLv3), whose console recipe reads a level out as base64. The snippets above are the same idea, adjusted to hand you the file directly.

3 · Convert it

Drop the downloaded .kitty into the converter at the top of this page. The editor writes container version 16; this tool reads it and produces the level gif. Read the report: anything the gif dialect cannot express is listed there, and if the solvability warning appears, a route may have changed.

4 · Put it in the game

  1. In the download step, pick a slot. The compilation loads a custom level only as an overwrite of one of its own level files, under exactly that filename.
  2. Find that file in the installed game — the RWK level gifs live under Images/RWK/ in the game folder.
  3. Back the original up, then replace it with your download. Verifying the game's files through your store puts the original back if you lose it.
  4. Start the game and choose that level.

Your level does not have to be the same size as the one it replaces — the game reads each level file's own dimensions. (Measured: a 200×95 level loaded in a slot whose original is 90×37.)
